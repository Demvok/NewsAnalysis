# LLM and Embedding Provider Modes

The LLM and embedding providers are configured independently through the
service `.env` files.

## LLM modes

Edit `analysis-layer/app/.env`.

### Local or LM Studio

```env
LLM_PROVIDER=local
LLM_URL=http://host.docker.internal:1234/v1
LLM_MODEL=google/gemma-4-e4b
LLM_API_KEY=fake_api_key
LLM_REASONING_PARAMETER=chat_template_kwargs.enable_thinking
```

The local server must expose an OpenAI-compatible `/v1/chat/completions`
endpoint.

### Google API

```env
LLM_PROVIDER=google
LLM_URL=https://generativelanguage.googleapis.com/v1beta/openai/
LLM_API_KEY=YOUR_GOOGLE_API_KEY
LLM_MODEL=gemma-3-27b-it
LLM_REASONING_PARAMETER=
```

Use a chat model available to the configured Google API key.

## Embedding modes

Edit `data-storage/app/.env`.

### Local GGUF model

```env
EMBEDDING_PROVIDER=local_model
EMBEDDING_MODEL=/app/models/embeddinggemma-300M-Q8_0.gguf
EMBEDDING_API_KEY=local_embedding_provider
EMBEDDING_DIMENSION=768
EMBEDDING_OUTPUT_DIMENSION=
```

Place the model at
`data-storage/models/embeddinggemma-300M-Q8_0.gguf`. This directory is
ignored by Git. Rebuild the storage image after adding or replacing the model.

### LM Studio embeddings

```env
EMBEDDING_PROVIDER=local
EMBEDDING_URL=http://host.docker.internal:1234/v1
EMBEDDING_MODEL=YOUR_LM_STUDIO_EMBEDDING_MODEL
EMBEDDING_API_KEY=local_embedding_provider
EMBEDDING_DIMENSION=768
EMBEDDING_OUTPUT_DIMENSION=
```

LM Studio must expose an OpenAI-compatible `/v1/embeddings` endpoint. The
selected model must produce 768-dimensional vectors.

### Google embeddings

```env
EMBEDDING_PROVIDER=google
EMBEDDING_URL=https://generativelanguage.googleapis.com/v1beta
EMBEDDING_API_KEY=YOUR_GOOGLE_API_KEY
EMBEDDING_MODEL=gemini-embedding-001
EMBEDDING_DIMENSION=768
EMBEDDING_OUTPUT_DIMENSION=768
EMBEDDING_BATCH_SIZE=80
```

Google embedding requests use the native batch endpoint and are split into
compatible request sizes automatically.

## Mixed configurations

The providers are independent. These combinations are supported:

| LLM | Embeddings |
| --- | --- |
| Local/LM Studio | Local GGUF |
| Local/LM Studio | LM Studio |
| Local/LM Studio | Google |
| Google | Local GGUF |
| Google | LM Studio |
| Google | Google |

## Applying changes

For regular environment changes:

```powershell
docker compose up -d --force-recreate analysis-layer data-storage
```

When adding or replacing the GGUF model, rebuild the storage image:

```powershell
docker compose up -d --build --force-recreate data-storage
```

## Reembedding after a provider change

Embedding models produce incompatible vector spaces. After changing the
embedding provider or model, regenerate all stored vectors:

```powershell
curl.exe -X POST http://localhost:8000/vectors/reembed-all
```

Do not mix vectors generated by different embedding models.
